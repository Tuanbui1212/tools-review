# S1 — Tiếp nhận & chuẩn hoá ảnh

> Trạng thái: **DRAFT**

## Làm gì

- Nhận ảnh rời / zip / thư mục (theo setting định dạng nạp), gắn với chapter.
- Sắp xếp ảnh theo số trong tên file (`1, 2, 10`, không phải `1, 10, 2`).
- Chuẩn hoá định dạng, kích thước; loại ảnh lỗi.
- Truyện cuộn dọc: ghép rồi cắt lại theo khoảng trắng giữa các khung.
- Lọc ảnh rác (bật/tắt): trang quảng cáo, credit nhóm dịch, watermark.

## Kiểm tra chất lượng

- Độ phân giải tối thiểu.
- Ảnh trùng, ảnh trống.
