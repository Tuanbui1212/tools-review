# M12 — Setting video (`video`)

> Trạng thái: **DRAFT** — đề xuất ban đầu, chốt khi làm M12. Theo D003.

| Setting | Giá trị ví dụ |
|---|---|
| Preset nền tảng | YouTube, TikTok/Shorts, Facebook Reels, tuỳ chỉnh |
| Tỉ lệ khung | 16:9, 9:16, 1:1 |
| Độ phân giải, fps, bitrate | 1080p, 30fps… |
| Độ dài tối đa | ví dụ Shorts ≤ 60 giây (tự cắt thành nhiều phần nếu dài hơn) |
| Hiệu ứng | zoom/pan, cuộn dọc, kiểu chuyển cảnh, tốc độ chuyển cảnh |
| Phụ đề | tắt / in vào video / file riêng; font, màu, vị trí |
| Nhạc nền | danh sách nhạc, âm lượng, tự hạ âm khi có giọng |
| Intro / outro / logo | file đính kèm hoặc mẫu thiết kế trong App |
| Thumbnail | tự tạo / không |

Preset nền tảng chọn xong sẽ tự điền tỉ lệ khung, độ phân giải, độ dài tối đa.
