# S4 — Nhận diện lời thoại (OCR)

> Trạng thái: **DRAFT**

## Làm gì

- Phát hiện bóng thoại, hộp dẫn truyện, chữ hiệu ứng (SFX).
- OCR từng vùng theo **ngôn ngữ nguồn** trong setting, gắn vào panel chứa nó.
- Phân loại: thoại, suy nghĩ, dẫn truyện, SFX.
- Hiệu chỉnh bằng **glossary** của project.
- Mỗi câu có điểm tin cậy.

## Dịch

Nếu ngôn ngữ kịch bản khác ngôn ngữ nguồn thì thêm bước dịch. Mình đề xuất dịch luôn trong bước viết kịch bản (S7) để giữ được ngữ cảnh, đồng thời vẫn lưu bản dịch từng câu để người dùng kiểm tra.

## Rủi ro

Font cách điệu, chữ chồng lên hình, chữ viết dọc.
