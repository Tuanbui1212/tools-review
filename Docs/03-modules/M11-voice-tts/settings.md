# M11 — Setting giọng đọc (`voice`)

> Trạng thái: **DRAFT** — đề xuất ban đầu, chốt khi làm M11 (sau khi thử TTS).

| Setting | Giá trị ví dụ |
|---|---|
| Nhà cung cấp / model TTS | chọn trong danh sách admin cho phép |
| Giọng dẫn truyện | chọn giọng |
| Giọng theo nhân vật | gán giọng cho từng nhân vật (khi có đọc thoại) |
| Giọng mặc định theo giới tính / độ tuổi | cho nhân vật chưa gán giọng |
| Tốc độ, cao độ, cảm xúc | |
| Từ điển phát âm | tên riêng → cách đọc |
| Khoảng nghỉ giữa các câu | mili giây |
| Ngưỡng so khớp speech-to-text | dưới ngưỡng thì tạo lại câu đó |
