1. Bóc tách Panel Tự động

Giao diện 3 cột trực quan: Kéo thả di chuyển, co giãn 4 góc, quét chuột vẽ thêm khung mới và lưu toạ độ vào Database trong vài giây.

🔄 Sơ đồ Tuần tự Luồng Xử lý (Sequence Workflow)

Cơ chế giao tiếp bất đồng bộ giữa Web Client, Main API, Celery Worker AI và PostgreSQL

Event-driven 
sequenceDiagram
    autonumber
    actor User as 👤 Người dùng (Web)
    participant Web as 🖥️ Web Client (React)
    participant Main as 🧠 Main API (FastAPI)
    participant Redis as ⚡ Redis Broker / PubSub
    participant Worker as 🤖 Worker AI (OpenCV Celery)
    participant DB as 🗄️ PostgreSQL

    User->>Web: Bấm "Tự động cắt toàn bộ Chapter"
    Web->>Main: POST /api/v1/chapters/{id}/extract-panels
    Main->>DB: Đổi chapter.status = "processing"
    Main->>Redis: Đẩy task "ai.extract_panels" vào ai_queue
    Main-->>Web: Trả về task_id (lắng nghe WebSocket)

    Note over Worker,Redis: Worker AI nhận task (hàng đợi ai_queue, -c 2)
    Worker->>Main: GET /internal/chapters/{id}/pages (Lấy danh sách trang ảnh)
    
    loop Duyệt tuần tự qua từng trang (1 -> N)
        Worker->>Main: GET /chapters/{id}/pages/{p_id}/file (Tải ảnh nhị phân)
        Worker->>Worker: OpenCV bóc rãnh trắng, xác định Bounding Box & crop ảnh
        Worker->>Main: PATCH /internal/tasks/{task_id}/progress (% = i/N * 100)
        Main->>Redis: Publish tiến độ vào channel:task:{task_id}
        Redis-->>Web: WebSocket bắn % Real-time (Thanh Progress Bar nhảy mượt mà)
    end

    Worker->>Main: POST /internal/chapters/{id}/panels/batch (Lưu toàn bộ toạ độ)
    Main->>DB: Ghi vào chapter_panels & đổi status = "ready"
    Worker->>Main: PATCH progress = 100%, status = "completed"
    Main-->>Web: WebSocket thông báo hoàn tất
    Web-->>User: Tải toạ độ lên Interactive Canvas để kiểm tra và chỉnh sửa
