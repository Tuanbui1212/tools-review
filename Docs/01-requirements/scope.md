# Phạm vi

> Trạng thái: **DRAFT** — cần chủ dự án xác nhận.

## Trong phạm vi (phiên bản đầu)

- Upload ảnh chapter, quản lý project / chapter.
- Toàn bộ pipeline S1–S11 với cổng duyệt.
- Nhiều loại truyện, nhiều phong cách kịch bản, nhiều preset video.
- Phân quyền admin / root / sub, mời người vào project.
- App để chỉnh sửa, Web để quản lý quy trình.

## Ngoài phạm vi (đề xuất)

- Tự crawl / tải truyện từ web (người dùng tự upload ảnh).
- Tự đăng video lên YouTube / TikTok (có thể làm ở phiên bản sau).

## Lưu ý bản quyền

Video review dùng ảnh truyện có bản quyền có thể bị Content ID hoặc khiếu nại trên YouTube/TikTok. Tool không giải quyết được vấn đề pháp lý, nhưng có thể giảm rủi ro: zoom vào panel thay vì hiện nguyên trang, thêm phần bình luận riêng.
